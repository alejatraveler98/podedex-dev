# Proyecto PokeDex

## Ejecutar:

1.  **Abrir terminal** en la carpeta.
2.  **Instalar:** `npm install` o `yarn install` o `pnpm install`
3.  **Iniciar:** `npm run dev` o `yarn dev` o `pnpm dev`
4.  **Ver en navegador** (la URL que diga la terminal).


## Estructura del proyecto en la carpeta src

components/        
context/    
hooks/                        
pages/            
routes/             
services/           
types/             

## Requisitios
✅ Lista de Pokemones             
✅ Detalle de cada Pokemon - Nombre, Imagen,  Peso, Tamaño, Tipos                 
✅ Implementación de estado global (Se uso Context)                
✅ Tipado               
✅ Efectos de carga y animaciones.                 
✅ Diseño atractivo y responsive.             
✅ Manejo de errores en las peticiones a la API.         
❌ Paginación o scroll infinito.       


## Aprendizaje 
Tipar por completo todo los componentes
Modularizar mas partes del código a componentes
Agregar páginación
Se intento abstraer gran parte de la lógica en los componentes pero aun se puede mejorar.
